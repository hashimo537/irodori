## このアプリの完成イメージ

> **家族の1週間を、色の帯で見る。**

縦軸に時間、横軸に曜日を並べた週タイムライン。子どもごとの色の帯で予定を表示するので、「火曜の夕方は長女のスイミングで手が空かない」がひと目で分かります。招待コードを1つ共有するだけで、パパも祖父母も同じ画面を見られます。

TimeTree との違いは「**縦軸＝時間**」の1点です。マス目式のカレンダーでは「17:00〜18:30」という時間の帯が見えません。そこだけを勝ちにいく設計です。

---

## 前提

- Docker が起動している
- `sail` エイリアスが使える（未設定なら `./vendor/bin/sail` に読み替え）
- Laravel Sail と Laravel 10 の基本（2-1／2-2／2-3 相当）が済んでいる
- PHP の OOP（クラス・継承・トレイト）の基本が分かる
